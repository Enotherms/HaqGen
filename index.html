Features

HaqGen features

HaqGen is a Decky Loader plugin built on lsfg-vk, the Linux version of Lossless Scaling's frame generation. It installs everything for you and keeps the controls simple, while still exposing the technical settings.

One-press setup

Installs lsfg-vk 2.0, finds your Lossless Scaling DLL and writes a valid config.

One launch option

Paste ~/haqgen %command% into any game. No per-game paths.

Profiles

A Default profile plus per-game profiles. The panel follows the game you play.

Simple controls

Off, 2x, 3x or 4x, and Battery, Balanced or Quality presets. Saved automatically.

FPS cap

Caps the game's real frame rate before frame generation for steadier motion.

Flatpak apps

Frame generation for emulators and launchers installed from Discover.

Troubleshooting

Health check with lsfg-vk's validator, a debug log and configuration repair.

Clean removal

Removes only what HaqGen created, and shows you the list first.

Get started

Install HaqGen

You need Decky Loader and Lossless Scaling on Steam, switched to the lsfg-vk beta branch.

  1. Install the pluginIn Decky settings › Developer, use Install Plugin From URL with the zip from the newest release.
  2. Run the setupOpen HaqGen in the Quick Access menu and press Set up.
  3. Add the launch optionPaste ~/haqgen %command% into each game's launch options.

Recommended settings and game support: read the full guide on GitHub.

Experimental

HaqEngine

HaqEngine is a second frame generation engine for the Steam Deck, written in Rust as a Vulkan layer by the same author.

  • Needs no Lossless Scaling DLL.
  • About 2 ms of GPU time per real frame at 1280×800.
  • Install it with one button in HaqGen 0.1.3 and newer, then choose lsfg-vk or HaqEngine per game.
