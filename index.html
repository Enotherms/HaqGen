HaqGen

Lossless Scaling frame generation for the Steam Deck

Download View on GitHub

Free and open source · Decky Loader plugin · Early release

HaqGen is a Decky Loader plugin built on lsfg-vk, the Linux version of Lossless Scaling's frame generation. It installs everything for you, gives you one launch option for all your games, and keeps the controls simple in the Steam Deck's Quick Access menu, while still exposing the technical settings.

Features

One-press setupInstalls lsfg-vk 2.0, finds your Lossless Scaling DLL and writes a valid config.
One launch optionPaste ~/haqgen %command% into any game.
ProfilesA Default profile plus per-game profiles. The panel follows the game you play.
Simple controlsOff · 2x · 3x · 4x, and Battery · Balanced · Quality presets.
FPS capCaps the game's real frame rate before frame generation for steadier frames.
Flatpak appsFrame generation for emulators and launchers from Discover.
TroubleshootingHealth check with lsfg-vk's validator, debug log and config repair.
Clean removalRemoves only what HaqGen created, and shows the list first.

Quick start

  1. Install Decky Loader.
  2. Install Lossless Scaling on Steam and switch it to the lsfg-vk beta branch.
  3. In Decky settings › Developer, use Install Plugin From URL with the zip from the latest release.
  4. Open HaqGen in the Quick Access menu and press Set up.
  5. Copy the launch option into each game: ~/haqgen %command%

Full guide, recommended settings and game support: README on GitHub.
